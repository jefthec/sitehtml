Sobre este projeto

Este site é um projeto acadêmico desenvolvido para a disciplina Tecnologias para Internet.

O objetivo é apresentar de forma organizada a história, as regras e os principais recordes da NFL, utilizando HTML semântico, CSS moderno e JavaScript para interatividade.
